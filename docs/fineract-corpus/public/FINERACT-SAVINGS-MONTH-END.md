# 貯蓄・定期預金の月末起点周年利息

要求ID: `FINERACT-SAVINGS-MONTH-END`。

新しい業務要求として、周年型8/9/10/11で開始日がその月の最終日なら、後続posting dateも各対象月の最終日とする。間隔は既存の1/3/6/12か月。最初の開始日が月末でなければ元のday-of-monthを維持し、短月のみ末日に丸める。短月を通ったために以後が月末型へ変わってはいけない。

貯蓄・定期預金の共通境界計算に適用する。通常型1/4/5/6/7、financialYearBeginningMonthの扱い、手動post-interest-as-onによる期間分割、既存の計算対象日での打切り、重複記帳防止を保持する。新しい型番号/勝手なAPIを追加しない。月末起点には2月28日（平年）・2月29日（閏年）・4月30日も含む。
